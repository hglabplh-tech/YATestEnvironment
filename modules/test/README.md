# yatest-test

Independent `test` library in YATestEnvironment.

Leiningen dependency: `[org.clojars.hglabplh/yatest-test "1.4.0-SNAPSHOT"]`.

This directory owns `src/main/clojure`, `src/main/java`, `src/main/resources`,
`src/test/clojure`, `src/test/java`, and `src/test/resources`.
Run `lein test`, `lein jar`, or `lein deploy clojars` here. Install sibling
dependencies first with `lein modules install` at the repository root.
Shared test helpers are available only through the development profile.
See the root README for whole-project builds and deployment order.
